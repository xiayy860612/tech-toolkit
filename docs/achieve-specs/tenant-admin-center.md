# Tenant Admin Center — 已落地的需求与设计（现状）

> 本文是**当前真实状态**的权威描述，随实现演进更新。过程性文档（澄清、调研、任务拆分）在 `specs/001-tenant-admin-center/`；架构层面见 [`docs/system-design/tenant-admin-center.md`](../system-design/tenant-admin-center.md)。
> 验证结论见 `specs/001-tenant-admin-center/verification.md`。

## 1. 范围

Tenant Admin Center 是租户管理员使用的后台，提供：

- **用户名密码登录**（含强制改密、失败锁定、统一失败提示）
- **用户（User）管理**：查看/搜索/创建/编辑/停用/启用
- **Account 管理**：一个 User 可有多个登录方式的 Account（首期仅"用户名密码"类型），Account 管理只在对应用户的详情页内
- **登录会话管理**：独立页面，查看本租户全部有效会话，强制下线单个会话或某用户的全部会话
- **审计日志**：记录与后端可查询（首期无界面）
- **多租户数据隔离**：所有数据按 `tenant-id` 隔离

**不在范围**：租户管理（本期所有用户的 `tenant-id` 恒为 `0`，没有租户入口页、租户编码、租户概览，也没有 `tenant` 表）、MFA/SSO/社交登录/自助注册/自助找回密码、自定义角色与细粒度权限、普通用户自助管理自己的会话、移动端适配、审计查询界面。

## 2. 术语

| 术语 | 含义 |
|---|---|
| **User** | 租户内"人"的身份主体；不持有密码或登录标识 |
| **Account** | User 的一种登录凭证/登录方式；有类型、登录标识（用户名，租户内大小写不敏感唯一）、状态、锁定状态 |
| **会话令牌** | 登录时由后端一次性交给 BFF 的机密，存于 HttpOnly Cookie；后端只存其 SHA-256 |
| **会话 id** | 会话的公开标识（UUID），用于会话管理页、审计与内部 JWT 的 `sid`；**不能**用来冒用会话 |
| **临时密码** | 管理员给定或系统生成（16 位）；创建/重置时仅返回一次，首次使用必须改密 |
| **租户管理员 / 普通用户** | 仅有的两种固定角色；只有租户管理员可使用管理能力 |

## 3. 角色与权限

- `TENANT_ADMIN` 可使用全部管理功能；`MEMBER` 登录后只能改密与退出，访问管理能力一律 403，界面导向 `/forbidden`。
- **授权所依据的角色以数据库当前值为准**：内部凭证不携带角色，管理员被降级后，其下一次请求即按新角色处理。
- 阻止使租户失去全部管理员的操作（`LAST_ADMIN`）；不能停用自己（`CANNOT_DISABLE_SELF`）。

## 4. 认证与会话规则

| 规则 | 现状 |
|---|---|
| 登录失败提示 | 统一"用户名或密码错误"；用户名不存在、密码错、Account/User 停用、被锁定响应完全一致，真实原因只写审计；用户名不存在时仍做等价哈希耗时 |
| 锁定 | 同一 Account 连续失败 **5** 次锁定 **15** 分钟，到期自动解锁，成功登录清零；管理员可手动解锁；阈值与时长可配置 |
| 密码规则 | 长度 ≥ 10；大写/小写/数字/符号至少 3 类；不得包含用户名；新密码不得与当前密码/临时密码相同 |
| 强制改密 | 临时密码登录后，仅 `/auth/me`、改密、登出可用，其余返回 403 `PASSWORD_CHANGE_REQUIRED` |
| 会话超时 | 空闲 **30** 分钟（滑动，续期写入每分钟最多一次）、绝对 **8** 小时，均可配置 |
| 会话撤销 | 退出登录、User 停用、Account 停用/删除、重置密码、管理员强制下线：撤销相应会话（修改密码撤销除当前会话外的其他会话）；撤销与审计在同一事务，下一次请求即失效 |
| 密码存储 | Argon2id（默认 48 MiB、4 次迭代、并行度 1，可配置）；任何接口、日志、审计都不含明文密码 |

## 5. 业务规则

- **User**：显示名非空且 ≤ 50；手机号可空（11 位大陆手机号）；邮箱可空；创建 User 时同时创建首个用户名密码 Account。
- **Account 用户名**：3–32 位，字母/数字/`.`/`_`/`-`，以字母或数字开头；规范化为 NFKC + 小写，租户内唯一（`USERNAME_TAKEN`）。
- **最后一个可用 Account**：删除/停用需 `confirm=true`，否则 409 `LAST_ACTIVE_ACCOUNT_CONFIRM_REQUIRED`。
- **并发**：User/Account 带乐观锁版本，冲突返回 409 `VERSION_CONFLICT`；"最后管理员"守卫在事务内加行锁。
- **会话管理**：当前会话不可下线（409 `CANNOT_REVOKE_CURRENT_SESSION`）；对自己的用户不提供"下线该用户全部会话"（409 `CANNOT_REVOKE_OWN_SESSIONS`）；`DELETE /sessions/{id}` 对不存在/已过期/其他租户的会话一律 204（幂等且不泄露存在性）；列表只返回有效会话，展示设备摘要（浏览器/系统）与 IP，**绝不返回**令牌、令牌哈希或原始 User-Agent。
- **审计**：登录成功/失败、锁定/解锁、登出、改密/重置密码、User 与 Account 的创建/编辑/停用/启用/删除、会话强制下线均有记录（操作者、对象、时间、结果、IP）；只追加，不可更新或删除。

## 6. 页面与路由（Tenant Admin BFF）

| 路由 | 页面 |
|---|---|
| `/login` | 登录（无租户入口，不含"忘记密码""企业 SSO""扫码登录""7 天内免登录"） |
| `/change-password` | 修改密码（含强制改密） |
| `/users`、`/users/new`、`/users/[id]/edit`、`/users/[id]` | 用户列表（搜索、状态页签、分页）、新建/编辑、详情（含 Account 管理区） |
| `/sessions` | 会话管理（独立页面，用户关键字筛选、强制下线） |
| `/forbidden` | 无权限 |

侧边栏只有「用户管理」「会话管理」；登录后默认落地 `/users`。界面语言为中文，桌面浏览器。

## 7. 接口

- 后端契约：`specs/001-tenant-admin-center/contracts/openapi.yaml`（22 个操作：`/auth/*`、`/users`、`/users/{id}`、停用/启用、`/users/{id}/accounts` 及其停用/启用/解锁/重置密码/删除、`/sessions`、`/sessions/{id}`、`/users/{id}/sessions`、`/audit-logs`）。
- BFF 自有接口：`contracts/bff-openapi.yaml`（`/api/v1/auth/login`、`/api/v1/auth/logout`）；其余 `/api/v1/*` 均为对后端契约的代理。
- 错误统一为 RFC 9457 `application/problem+json`，含稳定的 `code`。

## 8. 质量现状

后端 152 个测试、行覆盖率 94.9%；前端 268 个测试、行覆盖率 ≥ 90%；Playwright E2E 11 项；SC-005 实测列表/搜索 p95 521 ms。各场景证据见 `specs/001-tenant-admin-center/verification.md`。
