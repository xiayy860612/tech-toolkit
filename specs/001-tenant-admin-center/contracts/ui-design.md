# UI Contract: Tenant Admin Center

**Feature**: [spec.md](../spec.md) · **Plan**: [plan.md](../plan.md)

界面设计参考：Claude Design 画板「后台管理页面设计」（https://claude.ai/artifact/Q2mjrAFS5zaGN5HTkTZWWZ ；链接的访问密钥不入库）。含 4 个画板（本期不涉及租户管理，`Main` 数据总览整页不采用）：`Login`、`Main`（数据总览）、`List`（筛选 + 表格 + 分页）、`Form`（分组表单 + 吸底操作栏）。本文定义本特性对它的**采用、裁剪与扩展**。设计稿为桌面宽度（1440），与 spec「桌面浏览器」一致；设计稿使用 flex-wrap，窗口收窄时应仍可用。

## 页面清单与设计稿映射

| 页面 | 路由 | 对应画板 | 满足需求 |
|---|---|---|---|
| 登录 | `/login` | `Login`（裁剪）；无租户入口，租户固定为 0 | US1-1/2/5、FR-005/007/008/015 |
| 强制改密 | `/change-password` | **新增**，沿用 `Form` 的卡片 + 吸底操作栏（或 `Login` 右侧表单样式） | FR-011a/011b |
| 用户列表 | `/users` | `List`（改造） | FR-016、US2-4 |
| 新建 / 编辑用户 | `/users/new`、`/users/:id/edit` | `Form`（改造） | FR-017/018、US2-1/2 |
| 用户详情（含登录账号区） | `/users/:id` | **新增**，沿用 `List` 的表格卡片样式；Account 管理只在本页内，**不设独立的 Account 管理页** | FR-019/020/020a/008a、US3 |
| 会话管理 | `/sessions` | **新增**，沿用 `List` 的筛选栏 + 表格 + 分页样式；**独立页面，不放在用户详情中** | FR-026–030、US5 |

## 与设计稿的差异（裁剪 / 改造 / 扩展）

### 裁剪（与 spec 不符，删除）

| 设计稿内容 | 处理 | 依据 |
|---|---|---|
| 登录页「忘记密码？」链接 | 删除 | spec：不做自助找回，由管理员重置 |
| 登录页「其他登录方式：企业 SSO / 扫码登录」 | 删除 | 首期仅用户名密码 |
| 登录页「7 天内免登录」 | 删除 | 绝对超时 8 小时（FR-010） |
| 登录页账号框占位「手机号 / 邮箱 / 用户名」 | 改为「用户名」 | 登录标识为租户内用户名 |
| 登录页品牌文案（订单、客户、实时看板…） | 改为与租户管理相关的文案（多租户隔离、可扩展的登录方式、操作审计） | 与产品范围一致 |
| 侧边栏「订单管理 / 商品管理 / 客户管理 / 系统设置 / 审计日志」 | 删除（审计日志界面 spec 已明确后续增强） | 非本期范围 |
| 总览（`Main`）整页：KPI、趋势折线图、渠道环形图、最近订单表、时间范围切换、导出报表 | 删除 | 本期不涉及租户管理，无租户概览/仪表盘需求（YAGNI） |
| 顶栏全局搜索、通知铃铛 | 删除 | 无对应需求 |
| 表单页：所属部门、数据权限范围、备注、"发送账号激活通知" | 删除 | spec 无此字段；无通知通道 |

### 改造

- **用户列表**（`List`）：筛选栏 = 关键词（显示名/用户名）+ 状态；状态页签 = 全部 / 启用 / 停用；表头 = 姓名、用户名、角色、状态、最近登录、操作（详情 / 编辑 / 停用·启用）；分页沿用设计稿 44px 按钮与"共 N 条，每页 M 条"。
- **新建/编辑用户**（`Form`）：分组卡片 =「基本信息」（姓名\*）+「账号与角色」（角色 2 选 1 单选卡片：租户管理员 / 普通用户；登录用户名\*；临时密码输入或"系统生成"；编辑自己时角色选择禁用并提示"不能修改自己的角色"）。吸底操作栏文案"有 N 项校验未通过"沿用。创建成功后弹出**一次性临时密码**展示框（复制按钮 + "关闭后不可再次查看"）。编辑页不含用户名/密码（解锁与重置密码在详情页的「登录账号」区操作）。

### 扩展（设计稿没有，按同一视觉语言新增）

- **用户详情页「登录账号」区**：展示用户名、状态（含"已锁定至 HH:mm"胶囊）、最近登录；操作仅「解锁」（仅锁定时出现）与「重置密码」（重置成功后展示一次性临时密码）。用户名密码内置于 User，不是 Account，所以这里没有 Account 列表、停用/删除或「新增 Account」；日后新增手机号、微信、OAuth2.0 等 Account 类型时，再在同一区下增加对应的列表与关联入口。用户信息卡里自己的「启用状态」开关禁用并提示"不能停用自己"。
- **会话管理页**（`/sessions`）：筛选栏 = 用户关键字；表格列 =「用户（显示名）、用户名、设备（浏览器/系统）、IP、登录时间、最近活跃、到期时间、操作」，分页沿用 List 样式；管理员自己的当前会话行显示「当前」胶囊且无操作；其余行有「强制下线」，非本人用户行另有「下线该用户全部会话」，两者均弹确认对话框；空态「当前没有有效的登录会话」；操作成功后列表刷新并 Toast 提示。
- **强制改密页**：当前密码、新密码（实时显示复杂度规则勾选）、确认新密码；未改密前整个外壳其他导航禁用。
- **会话过期**：任一接口 401 → 跳转 `/login?next=<原目标页>`，登录后返回（Edge Case）。
- **统一错误态**：登录统一提示"用户名或密码错误"；409/403/404 以行内提示或 Toast 呈现，文案按 `code` 映射。
- **空/加载/失败态**：列表空态、骨架屏、请求失败重试，均沿用卡片样式。

## 设计稿落地注意

- 设计稿是 Design Component 格式的静态/示例页，数据为示例数据，**视觉与布局为准，不是代码来源**；组件以 shadcn 风格（Radix 原语 + Tailwind）在 `frontend/src/components/ui/` 重新实现，Token 落到 `globals.css`。
- 实现时若发现设计稿与 WCAG 对比度冲突，以可访问性为准并回写本文。

## 侧边栏收起与响应式（FR-031）

- **侧边栏**：宽屏（≥ 1024px）默认展开（232px），顶栏左侧有「收起/展开」按钮；收起后宽 64px，只显示图标（带 `title`/`aria-label`），内容区变宽；选择保存在浏览器本地（`localStorage`，读写失败时退回默认）。
- **窄屏**（< 1024px）：侧边栏默认隐藏，顶栏按钮打开抽屉式侧栏（带遮罩，点击遮罩、按 Esc 或选择菜单项后关闭）；顶栏面包屑与用户名在窄屏下收紧（用户名文字隐藏，只留头像）。
- **内容区**：卡片与表单随宽度单列堆叠；表格容器 `overflow-x-auto`，页面本身不出现横向滚动；筛选栏与分页在窄屏换行。
- **登录页**：窄屏隐藏左侧品牌栏，表单居中占满宽度（现状已如此，保持）。
